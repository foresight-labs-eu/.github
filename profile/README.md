# Foresight Labs

Foresight Labs is an AI research lab in the Netherlands. We publish open research, build open-source agents, and host models in the EU. We are the lab behind [Nodecode](https://nodecode.ai).

## What we work on

- **Open research.** Reports and notes on agents, harnesses and models, numbered and published at [foresight-labs.eu/research](https://foresight-labs.eu/research).
- **Open-source agents.** [Nodecode](https://nodecode.ai) is a coding agent written in Lisp that evolves: code is data, so it can redefine itself while it runs, and cells extend its workspace with new tools, rooms, providers and skills. MIT licensed, source at [nodecode-ai/nodecode](https://github.com/nodecode-ai/nodecode).
- **Models hosted in the EU.** Hosted inference in Europe, private by default. See [pricing](https://foresight-labs.eu/pricing).
- **Cybersecurity.** Unrestricted models and finetunes for security research.
